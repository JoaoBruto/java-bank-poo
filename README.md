# Sistema Bancário Simples (Java)

Projeto de estudo desenvolvido para praticar os fundamentos da linguagem Java, com foco em Programação Orientada a Objetos (POO).

## 🎯 Objetivo

Simular um sistema bancário básico via terminal, permitindo criar contas, realizar depósitos, saques e consultar saldo — aplicando na prática os conceitos estudados em um curso introdutório de Java.

## 🧠 Conceitos aplicados

Este projeto foi construído para colocar em prática os seguintes conteúdos:

- Tipos primitivos (`int`, `double`, `boolean`, `char`, etc.)
- Estruturas condicionais (`if`, `else`, `switch`)
- Estruturas de repetição (`for`, `while`)
- Arrays
- Casting implícito e explícito
- Programação Orientada a Objetos:
  - Classes e objetos
  - Construtores
  - Modificadores de acesso (`private`, `public`, `protected`)
  - Herança
  - Polimorfismo

## 🏗️ Estrutura planejada

- `Conta` — classe base representando uma conta bancária genérica
- `ContaCorrente` — subclasse de `Conta` com regras específicas
- `ContaPoupanca` — subclasse de `Conta` com regras específicas
- `Banco` (ou similar) — gerencia a coleção de contas
- `Main` — menu interativo no console

*(Essa estrutura pode mudar conforme o projeto evolui.)*

## 🚧 Status do projeto

Em desenvolvimento — projeto de aprendizado construído passo a passo, com foco em entender cada decisão de design antes de implementar.

## 📚 Contexto

Este é o primeiro projeto prático após a conclusão de um curso introdutório de Java, com o objetivo de consolidar o aprendizado e começar a construir um portfólio.
